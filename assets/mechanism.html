expertcache · residency is a byte budget, not a slot count

Routes acquire a transactional lease over the union of their experts' parameter bytes before any copy or compute. The same Residency.lease code drives the animation, the tests and the receipts.

Bytes, not slots. A 48-wide expert costs 3× a 16-wide one; variable payloads make eviction a per-byte value decision, checked against real parameter payloads.
Transactional leases. Over-budget routes fail before mutation; nested pins are refcounted; exceptions release pins and cannot leave phantom residency.
Honest ledger. copied bytes = actual deepcopied payloads (asserted equal to planner accounting); transfer-latency figures are labeled modeled, never measured.
